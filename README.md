# SnapCapture

SnapCapture 是一款专为 Windows 平台打造的 **原生高保真、极致性能截图工具**。

本项目使用 **纯 C++11 + Win32 SDK + GDI/GDI+** 开发，不依赖任何第三方运行时或动态链接库（DLL），是一个单一独立的可执行程序（体积仅 2.6MB），拥有瞬间启动（<5ms）和超低内存占用（约 2.5MB）的绝对优势。

在最新的版本中，我们针对大尺寸高分屏幕进行了 **物理像素级渲染重构 (v2.1)** 并全面升级了 **方正极简现代暗黑 UI 系统 (v2.2)**，去除了所有多余的 Emoji，打造出极具科技感的高品质扁平化桌面软件。v2.3 引入了 **DWM 智能窗口探测与一键选中 (Smart Window Detection)**，鼠标悬停即可自动高亮识别应用窗口，单击直接框选。v2.4 全面支持 **高保真可编辑文字标注与后编辑引擎 (Editable Text Annotation)**，支持任意位置拖拽移动、属性实时同步、鼠标滚轮字号平滑无级缩放以及一键快捷删除。

## 核心亮点与渲染引擎重构 (v2.1)

为了提供黄油般顺滑的框选与标注体验，SnapCapture 实现了独创的 **物理显存级渲染架构**，特别针对 2K / 4K 高清分辨率及多监视器环境进行了深度优化：

*   **双缓冲资源预分配 (Zero-Allocation Render Path)**：截图启动时一次性预先分配全屏离屏双缓冲 DC 和位图，彻底规避了 `WM_PAINT` 渲染循环中高频申请/销毁大尺寸 GDI 位图造成的内核分配压力。
*   **遮罩单次预渲染 (Single-Pass Alpha Blending)**：在初始帧单次完成全屏暗黑半透明遮罩与原图的像素级融合并缓存，使拖动框选、边缘拉伸过程中的全屏涂覆退化为纯显存级的硬件拷贝 (`BitBlt`)，**渲染开销降低 99%，帧率锁定 144+ FPS 物理极限**。
*   **瞬时局部抠图 (Instant Crop Blitting)**：选区内的原画还原仅通过 GPU 针对选区矩形区域进行极速块传输，最大化节省总带宽，彻底消除拖拽延迟与画面撕裂。

## 方正极简现代暗黑 UI 系统 (v2.2)

项目全面升级为 **极简科技暗黑视觉设计**，重塑为专业、对称、方正的工业级格调：

*   **黄金比例与屏幕居中 (Symmetric Centered Layout)**：设置面板升级为 `480 x 380` 黄金视感比例，并在屏幕正中央高精度自动居中对齐弹出。
*   **方正清爽工具栏**：截图底部的功能键全部规范化为对称的 2字纯中文按钮（`矩形`、`箭头`、`撤销`、`确定`、`保存`、`取消`），呈现无干扰的纯粹扁平网格效果。
*   **全局 GDI+ 自绘 (Owner-Draw) 控件**：全部按钮通过 `BS_OWNERDRAW` 与**按钮子类化 (Subclassing) 悬停追踪技术**重绘，完美渲染出高精度扁平色彩与 Hover/Pressed 动态颜色变换。
*   **自制暗黑方正复选框 (Custom Flat Checkboxes)**：彻底替换 Windows 默认的惨白勾选框，在 `RGB(30, 30, 30)` 极暗底色上自绘出方正浅灰边框，勾选时呈现现代品牌蓝 `RGB(0, 174, 255)` 底色与纯白高精度抗锯齿矢量对号。

## DWM 智能窗口探测引擎 (v2.3)

SnapCapture 现已集成 Windows DWM (Desktop Window Manager) 底层 API，实现了业界领先的 **智能窗口探测与一键选中** 功能：

*   **悬停即亮 (Hover-to-Highlight)**：按下截图快捷键后，鼠标在桌面上移动时，当前光标所在位置的应用窗口会被**实时自动识别并高亮显示** —— 窗口区域瞬间脱除暗色遮罩，并以品牌蓝 `#00AEFF` 描边，清晰标示出即将被选中的窗口范围。
*   **单击即选 (Click-to-Snap)**：对准目标窗口后，**单击鼠标左键**即可瞬间将选区精确锁定到该窗口的真实物理边界上，无需手动逐像素对齐。
*   **长按拖拽不受影响 (Drag Override)**：如果您按住鼠标左键并拖动超过 5 像素，系统将自动识别为传统的手动矩形框选模式，完全不影响自由框选的灵活性。
*   **DWM 精确边界 (DwmGetWindowAttribute)**：使用 `DWMWA_EXTENDED_FRAME_BOUNDS` 获取窗口的**真实可见区域**，自动排除 Windows 系统为窗口添加的阴影和透明边距，保证截图无多余留白。
*   **智能过滤算法**：自动忽略不可见窗口、已隐藏 (Cloaked) 的虚拟桌面窗口、工具窗口 (ToolWindow)、系统 Shell 窗口、过小的隐形控件，以及截图覆盖层自身，精准锁定用户真正想要截取的目标窗口。

## 高保真可编辑文字标注与后编辑引擎 (v2.4)

为了在截图中标注时提供完美的文字处理能力，SnapCapture 自研了 **Native 高保真文字排版与后编辑引擎**：

*   **500ms 实时光标闪烁与虚线边界**：进入文字输入模式后，点击任意选区即可开启即时录入。输入框自适应文本长度，并伴随天蓝色现代虚线输入框以及 **500ms 高精度闪烁光标竖线**，极具现代文本编辑器质感。
*   **选中高亮与位置自由平移 (Post-Edit Text Dragging)**：写好文字后，可点击文字按钮退出输入模式或直接单击该文字，文字周围会以品牌蓝 `#00AEFF` 渲染精美虚线选框。按住鼠标左键即可**平滑拖拽移动到选区内的任意位置**。
*   **鼠标滚轮字号平滑无级缩放 (Smooth Font Resizing)**：当某个文字处于选中状态时，您可以使用 **鼠标滚轮** 进行缩放。系统采用独创的高精度线性映射公式（`8 + thickness * 3`），将滚轮滚动事件完美地转换为 `11px` 至 `53px` 的字号平滑无级调节，直观顺滑。
*   **属性工具栏智能同步**：点击任意文字时，下方属性调色面板的粗细点和 7色色块会**自动同步切换**为该文字的当前尺寸和颜色；您可以在此面板上直接点击切换不同的粗细和颜色，被选中的文字会瞬间完成重绘渲染。
*   **快捷一键擦除 (Instant Deletion)**：在选中某个文字时，无需进入复杂的右键菜单，**直接按下键盘的 `Delete` 键或 `Backspace` 退格键**，即可顺滑地将该文字从画布上擦除。
*   **方正拼音汉字完美直输**：完美承接系统 `WM_CHAR` 与 `WM_KEYDOWN` 消息链，完美支持主流的微软拼音、搜狗五笔等输入法中文直输，不卡字、不跳字。

## 极简使用指南（适合新手小白，免编译）

如果您不需要修改源代码，**完全不需要进行任何复杂的编译**，只需 3 步即可直接使用：

### 第一步：下载可执行程序
1. 访问本 GitHub 项目页面，在文件列表中点击 **[CaptureTool.exe](https://github.com/combodevy/SnapCapture/raw/main/CaptureTool.exe)**。
2. 在打开的页面中，点击右侧的 **Download** 按钮，将可执行文件下载到您的电脑中。
3. **重要提示**：建议将 `CaptureTool.exe` 放置在一个专门的文件夹内（例如 `D:\Tools\SnapCapture\`），因为在您修改设置时，程序会在同级目录下自动生成一个 `config.json` 配置文件。

### 第二步：运行程序
- 双击运行 `CaptureTool.exe`。
- 运行后，程序将以极低功耗静默运行。您可以在 Windows 屏幕右下角（系统托盘）看到一个**天蓝色的小相机图标**。

### 第三步：配置与截图
1. **右键点击** 右下角的小相机图标，在弹出的菜单中选择 **"设置中心"**。
2. 窗口会自动居中弹出，点击 **"录入新快捷键"**。
3. 键盘按下您想自定义的组合键（例如 `Ctrl + Shift + A`、`F12`、`PrintScreen`），或者直接按下您**鼠标的侧键（Mouse4 / Mouse5）**，程序会自动录入。
4. 勾选 **"阻止其他应用接收此按键"** 可防止与其他软件发生快捷键冲突；勾选 **"开机自启动"** 即可在每次开机时自动后台运行（免管理员权限）。
5. 点击 **"保存设置"** 即可生效！按下快捷键瞬间即可开启流畅的 144Hz 极速截图体验。

## 开发者与发烧友编译指南（从源码构建）

如果您想修改代码并自己编译出专属于您的程序，请按照以下步骤配置开发环境并进行编译：

### 第一步：安装 C++ 编译器（MinGW-w64）
要在 Windows 上编译 C++ 源码，您需要安装 GCC 编译工具链：

1. **下载编译器**：
   - 推荐下载轻量且免安装的 MinGW 构建包，可以访问 [WinLibs](https://winlibs.com/) 或从 [Github Release](https://github.com/brechtsanders/winlibs_mingw/releases) 下载 `Win64` 版本的 `.zip` 压缩包（例如 `mingw-w64-v11.x` UCRT版）。
2. **解压文件**：
   - 将下载好的 `.zip` 文件解压到您的电脑中（例如解压到 `C:\mingw64\`）。
3. **配置环境变量 PATH**（让系统在任何地方都能识别 `g++` 编译命令）：
   - 在 Windows 搜索栏输入 **"编辑系统环境变量"** 并打开。
   - 点击下方的 **"环境变量"** 按钮。
   - 在 "系统变量" 区域找到名为 **"Path"** 的变量，双击它。
   - 点击右侧的 **"新建"**，然后输入您的编译器 `bin` 目录路径（例如 `C:\mingw64\bin`）。
   - 一路点击 **"确定"** 保存退出。
4. **验证安装**：
   - 按下键盘上的 `Win + R` 打开运行窗口，输入 `cmd` 回车打开命令行。
   - 输入 `g++ --version` 并回车。如果显示出 GCC 的版本号信息，说明编译器已经成功配置好了！

### 第二步：下载本项目源码
1. 点击本 GitHub 仓库右上角的 **Code** 按钮，选择 **Download ZIP**。
2. 下载后解压到本地文件夹（例如 `D:\Projects\SnapCapture\`）。

### 第三步：一键极速编译
1. 打开解压后的项目文件夹。
2. 按住键盘上的 **Shift 键**，同时在文件夹的空白处**右键点击**，在弹出的右键菜单中选择 **"在此处打开 PowerShell 窗口"**（Windows 11 则是"在终端中打开"）。
3. 在打开的 PowerShell 窗口中，直接输入以下命令并回车：
   ```powershell
   .\build.ps1
   ```
4. **编译完成**：
   编译过程大约需要 4~6 秒。当看到绿色的 `Success! CaptureTool.exe compiled!` 提示时，说明程序已成功在当前目录下构建完毕！
   - 本项目采用 `-O3` 极致性能级优化编译。
   - 开启 `-static` 纯静态编译选项，将 GDI+ 等全部运行时静态打包进可执行文件中，体积仅 2.6MB，拷贝到任何 Windows 电脑上都可以无感瞬间运行！

## 截图功能使用说明书

*   **智能窗口选中**：按下截图快捷键后，鼠标悬停到任意应用程序窗口上会自动高亮显示该窗口的边界。**单击左键**即可一键精确选中该窗口；**长按左键并拖动**则进入传统的自由矩形框选模式。
*   **1:1 高清物理捕获**：高精度 DPI 自适应，支持多显示器不同缩放比例，截图绝不模糊或偏移。
*   **8方向调节与自由平移**：选区完成后，四周会出现 8 个控制点，鼠标滑过自动变成拉伸光标；拖拽控制点可缩放大小，拖选区内部可限制在屏幕边界内整体平移。
*   **混合矢量标注**：
    *   点击 **"矩形"** 可在选区内拖画出扁平矩形框。
    *   点击 **"箭头"** 可在选区内拖画出指向性矢量箭头。
    *   点击 **"文字"** 即可在选区内任意位置单击输入文本，享有 **高精度闪烁光标** 和虚线文本框的极致录入体验。输入完成后回车或点击空白处即可保存文本。
    *   **后编辑拖拽与字号缩放**：单击已写好的文字（处于文字模式），可将其选中并以品牌蓝虚线高亮。按住鼠标左键即可**自由拖动移动文字位置**；在选中状态下**滚动鼠标滚轮**，即可极速无级调节字号大小（11px ~ 53px 顺滑无缝过渡）。
    *   **快捷键一键删除**：选中某个文字时，直接按键盘的 **Delete 键** 或 **Backspace 键**，即可瞬间抹除此文字。
*   **实时属性调色面板与同步**：进入任意标注模式（矩形、箭头、文字）时，工具栏下方会平滑展开属性子面板，支持三档粗细及 7 种专业莫兰迪暗黑配色调节。在文字模式下，点击任何文字会**瞬间自动同步**属性栏的状态；在属性栏上进行任何修改会立刻重绘所选文字的粗细/颜色。
*   **Photoshop 级多级撤销**：标注画错了？直接点击 **"撤销"** 按钮，即可由新到旧依次退回擦除您的标注，具有极高的容错率。
*   **误触保护机制**：精准判定并拦截对主工具栏和子属性面板空白灰色区域的任何连续快速点击，绝不误触重置选区或丢失已画标注。
*   **确定 & 保存**：
    *   点击 **"确定"**：截图（含高保真标注）将静默复制到剪贴板，同时支持 **CF_DIB** (兼容 Word、画图) 与 **PNG** (兼容 Discord、Photoshop) 双格式，按下 `Ctrl + V` 即可完美粘贴发送。
    *   点击 **"保存"**：在将截图存入剪贴板的同时，会自动弹出 Windows 标准保存文件对话框，供您导出为高画质 PNG 图片。
