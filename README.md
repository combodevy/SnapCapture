# SnapCapture (CaptureTool)

Windows 平台轻量级原生截图与标注工具。

## 项目简介

SnapCapture 是一款基于 **C++11**、**Win32 API** 和 **GDI/GDI+** 开发的 Windows 桌面截图工具。本项目致力于在保证极低系统资源占用的前提下，提供高效、流畅的截图体验和完备的矢量与文本标注功能。

### 技术特点

- **无第三方依赖**：除 Windows 系统标准 API 外，不引入任何第三方运行时或动态链接库（DLL），可编译为单一、独立的静态可执行程序。
- **高效性能与极低开销**：采用双缓冲离屏渲染，预分配 DC 与位图资源，最大程度减少 `WM_PAINT` 消息处理中的高频内存申请与销毁。普通运行状态下内存占用约 2.5MB。
- **高 DPI 适配**：支持 Windows 系统级 DPI 感知，在高清屏与多监视器混合缩放环境下保证截图及标注的分辨率与清晰度。

## 核心功能

### 1. 截图与选区模式

- **DWM 智能窗口探测**：调用 Windows 桌面窗口管理器（DWM）API，获取精确的可见窗口物理边界（使用 `DWMWA_EXTENDED_FRAME_BOUNDS` 属性排除系统窗口阴影与透明外边距），支持鼠标悬停实时高亮选中，单击快速锁定目标窗口。
- **自由区域框选**：支持鼠标左键拖拽自由调整截图矩形选区。
- **八向边缘调整**：选区确定后，可在四周 8 个拉伸手柄处自由调节截图尺寸，支持全局平移。

### 2. 丰富图形与矢量标注

- **矩形与圆角矩形工具**：支持拖画矩形边框。边框的圆角半径（Round Radius）支持：
  - **参数持久化**：保存在本地 `config.json` 配置文件中，下次启动自动加载。
  - **悬停快捷编辑**：鼠标移动到圆角半径数值标签上时，光标自动切换为 `IDC_IBEAM`（输入状态），并显示高亮焦点框，可通过键盘直接输入数值调整圆角半径（支持 0–30px 范围），回车或移开后自动保存更新。
- **圆形/椭圆工具**：支持拖画矢量圆形或椭圆形，用于快速定位目标区域。
- **矢量箭头工具**：拖画指向性箭头，笔触顺滑。
- **撤销机制**：提供基于历史记录的动作撤销（Undo）机制，支持依次退回并擦除已画的标注元素。

### 3. 可变换文本标注引擎

- **键盘光标与序列输入 (Caret Navigation)**：支持键盘方向键（`←` / `→`）、`Home` 和 `End` 键自由移动输入光标，并支持在任意文字中间进行退格（`Backspace`）、删除（`Delete`）及中英文文字插入，具有完整的字符编辑体验。
- **字体样式选择**：支持调用 Windows 系统字体选择对话框，可自定义选择字体名称（如微软雅黑、等线等）、字号、加粗（Bold）及斜体（Italic）等样式，并精确映射渲染至 GDI+ 绘图上下文中。
- **任意角度旋转与等比缩放**：
  - 选中已绘制的文本框后，右下角带有专用旋转手柄，支持鼠标拖拽进行 `0°` 至 `360°` 的任意角度旋转。
  - 支持通过左上、右上、左下三个微型蓝色角手柄拖拽，对文本框进行等比例大小缩放（支持 `0.1x` 至 `15x`），亦可使用鼠标滚轮平滑微调字号。
  - 双击任何已绘制的文本，将直接在原位以当前倾斜角和缩放比例重新进入编辑模式，支持即时修改。
- **智能交互光标**：鼠标悬停在文本不同控制手柄（缩放点、旋转手柄、文字主体、空白区）时，指针会自动切换为对应的拉伸、旋转、移动或十字光标，交互指示明确，点击感应半径达 20 像素，避免误触。

### 4. 系统集成与设置

- **全局快捷键注册**：支持通过设置面板录入自定义全局快捷键。支持键盘组合键或鼠标侧键（Mouse4 / Mouse5，即 XButton1 / XButton2）。可选开启“按键吞噬（Suppress）”功能拦截系统消息以避免按键冲突。
- **系统托盘与设置面板**：静默运行于系统托盘。右键托盘图标可打开纯自绘的扁平暗黑风格设置面板，可在此配置开机自启动、修改保存目录、修改快捷键及自定义颜色等。
- **开机自启动**：利用注册表实现非管理员权限下的用户级自动启动（写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`）。
- **双格式剪贴板支持**：点击“确定”后，截图将以 `CF_DIB`（传统兼容格式，如 Office/画图）与 `PNG`（保留透明通道，如 Discord/Photoshop）双格式写入 Windows 系统剪贴板，提供高保真的拷贝粘贴表现。

## 配置文件说明

程序启动时，将在同级目录下创建或读取 `config.json` 配置文件。以下为主要参数的结构说明：

```json
{
  "hotkey": {
    "type": "mouse",           // 触发类型: "keyboard" 或 "mouse"
    "keys": [],                // 键盘快捷键组合 (例如 ["ctrl", "shift", "a"])
    "mouse_button": "x1",      // 鼠标侧键名称 (例如 "x1" 或 "x2")
    "suppress": true           // 是否阻止该快捷键被传递给其他应用程序
  },
  "auto_start": true,          // 是否开机自启动
  "save_to_clipboard": true,   // 是否默认保存到剪贴板
  "save_directory": "",        // 截图自动保存目录 (为空时仅保存至剪贴板或弹出保存框)
  "notification": true,        // 是否开启消息提示
  "round_radius": 25,          // 矩形标注的圆角半径 (0-30 像素)
  "capture_mode": "region",    // 默认截图模式: "region" (区域) 或 "window" (窗口)
  "custom_color_1": 4294967168 // 用户自定义调色板颜色 (ARGB 十进制格式)
}
```

## 编译指南

### 开发环境要求
- **操作系统**：Windows 7 或更高版本。
- **编译器**：支持 C++11 标准的 GCC 编译器（例如 MinGW-w64 11.x 或更高版本）。
- **Shell**：PowerShell (用于运行构建脚本)。

### 编译步骤

1. 打开项目文件夹。
2. 启动 PowerShell 或 Windows Terminal 并定位到项目根目录。
3. 执行编译脚本：
   ```powershell
   .\build.ps1
   ```
4. 脚本将使用以下命令进行编译：
   ```powershell
   g++ -std=c++11 -O3 -mwindows -static main.cpp -lgdi32 -lgdiplus -lshlwapi -luser32 -lshell32 -lole32 -lcomdlg32 -ldwmapi -o CaptureTool.exe
   ```
   *注：使用 `-O3` 开启编译器优化；`-static` 选项会将全部依赖静态编译打包；`-mwindows` 选项可隐藏黑色的命令行控制台窗口。*
5. 编译完成后，会在当前目录生成单一的静态可执行文件 `CaptureTool.exe`，体积约 2.6MB。

## 使用指南

### 基础操作

1. **启动程序**：双击运行 `CaptureTool.exe`，程序将进入后台并在系统托盘生成相机图标。
2. **快捷截图**：按下配置的快捷键（默认注册鼠标侧键 X1），系统将捕获当前屏幕并生成半透明遮罩。
3. **窗口/区域框选**：
   - 鼠标在各应用窗口上移动时，系统会自动探测并描边高亮窗口。**单击左键**即可精确捕捉当前高亮窗口。
   - 在空白区域**长按并拖拽鼠标**可手动拉出截图选区。
4. **标注元素编辑**：
   - 选择底部的**矩形**、**圆形**、**箭头**、**文字**按钮在截图上拖拽进行标注。
   - 标注时可展开下方的属性面板，调节画笔粗细与颜色。
   - 绘制文字标注后，可以通过拖动控制点对文本进行缩放、旋转或位移；**双击**可原地进入编辑状态，支持键盘方向键插入文字；在选中状态下按 `Delete` 键或 `Backspace` 键即可将其删除。
5. **保存与复制**：
   - 单击 **"确定"**：保存截图至剪贴板。
   - 单击 **"保存"**：在保存至剪贴板的同时，弹出保存对话框，将截图另存为本地 PNG 文件。
   - 单击 **"取消"** / 按下 `Esc` 键：退出截图界面，丢弃当前截图。
