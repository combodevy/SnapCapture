# SnapCapture

SnapCapture 是一款专为 Windows 平台打造的 **原生高保真、极致性能截图工具**。

本项目使用 **纯 C++11 + Win32 SDK + GDI/GDI+** 开发，不依赖任何第三方运行时或动态链接库（DLL），是一个单一独立的可执行程序（体积仅 2.6MB），拥有瞬间启动（<5ms）和超低内存占用（约 2.5MB）的绝对优势。

---

## ⚡️ 核心亮点与渲染引擎重构 (v2.1)

为了提供黄油般顺滑的框选与标注体验，SnapCapture 实现了独创的 **物理显存级渲染架构**，特别针对 2K / 4K 高清分辨率及多监视器环境进行了深度优化：

*   **双缓冲资源预分配 (Zero-Allocation Render Path)**：截图启动时一次性预先分配全屏离屏双缓冲 DC 和位图，彻底规避了 `WM_PAINT` 渲染循环中高频申请/销毁大尺寸 GDI 位图造成的内核分配抖动与拖拽卡顿。
*   **遮罩单次预渲染 (Single-Pass Alpha Blending)**：在初始帧单次完成全屏暗黑半透明遮罩与原图的像素级融合并缓存，使拖动框选、边缘拉伸过程中的全屏涂覆退化为纯显存级的硬件拷贝 (`BitBlt`)，**渲染开销降低 99%，帧率锁定 144+ FPS 物理极限**。
*   **瞬时局部抠图 (Instant Crop Blitting)**：选区内的原画还原仅通过 GPU 针对选区矩形区域进行极速块传输，最大化节省总带宽，彻底消除拖拽延迟。

## 💎 方正极简现代暗黑 UI 系统 (v2.2)

项目全面升级为 **极简科技暗黑视觉设计**，移除了所有多余的彩色 Emoji 图标，重塑为专业、对称、方正的工业级格调：

*   **黄金比例与屏幕居中 (Symmetric Centered Layout)**：设置面板升级为 `480 x 380` 黄金视感比例，并支持在屏幕正中央高精度自动居中对齐弹出。
*   **Emoji-Free 方正清爽工具栏**：截图底部的功能键全部规范化为对称的 2字纯中文按钮（`矩形`、`箭头`、`撤销`、`确定`、`保存`、`取消`），呈现无干扰的纯粹扁平网格效果。
*   **全局 GDI+ 自绘 (Owner-Draw) 控件**：全部按钮通过 `BS_OWNERDRAW` 与**按钮子类化 (Subclassing) 悬停追踪技术**重绘，完美渲染出高精度扁平色彩与 Hover/Pressed 动态颜色变换。
*   **自制暗黑方正复选框 (Custom Flat Checkboxes)**：彻底替换 Windows 默认的惨白勾选框，在 `RGB(30, 30, 30)` 极暗底色上自绘出方正浅灰边框，勾选时呈现现代品牌蓝 `RGB(0, 174, 255)` 底色与纯白高精度矢量对号。

## 🌟 核心功能特性

1.  **DPI-Aware 1:1 高精度像素捕获**：原生适配多显示器不同缩放比例（100%、125%、150% 等），杜绝截图偏移、放大或发虚。
2.  **8 方向自适应调节手柄**：提供 8 个方正控制点，支持鼠标滑过时智能切换光标类型（`IDC_SIZENWSE` 等）以及 8 方向自由调节大小与边界约束的整体平移。
3.  **高性能低级内核钩子 (Low-Level Hooks)**：通过 `WH_KEYBOARD_LL` 和 `WH_MOUSE_LL` 拦截快捷键。
4.  **交互式快捷键/侧键录入**：支持键盘任意组合键（如 `Ctrl + Shift + A`、`PrintScreen`、`F12`）或鼠标侧键（`Mouse4` / `Mouse5`）的智能录制，提供全局按键冲突吞噬（Suppress）开关。
5.  **CF_DIB + PNG 双格式静默写入剪贴板**：
    *   *CF_DIB*：完美支持 Word、画图等传统 Office 办公套件。
    *   *PNG*：高保真保留 Alpha 透明通道，完美兼容 Discord、Photoshop 等现代社交和修图软件，且静默拷贝不打扰日常工作。
6.  **免提权开机自启动**：读写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 注册表，无需 UAC 管理员权限，即可一键随系统自启。
7.  **混合标注与多级撤销**：提供矩形框、矢量抗锯齿箭头的混合叠加标注，支持属性面板三档粗细（`2px`, `4px`, `8px`）及 7色调色板的实时调整，并支持 `撤销` 级联回退。
8.  **无物理越界点击重置保护**：精准判定并拦截对主工具栏和子属性面板空白区域的任何快速点击，绝不误触重置选区或丢失已画标注。

## 🛠 一键静态编译指南

本项目使用 MinGW GCC 编译器。请确保您的系统 PATH 环境变量中包含 `g++.exe`。

在项目根目录下，以 PowerShell 运行以下命令进行一键编译：

```powershell
.\build.ps1
```

编译脚本将自动以 **`-O3` 最大优化**、**`-mwindows` 隐藏控制台命令行** 以及 **`-static` 纯静态编译** 生成独立的 `CaptureTool.exe`，无需打包任何动态库，拷贝即可在任何 Windows 7/10/11 电脑上双击瞬间运行。
